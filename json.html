JSON

Una forma sencilla de almacenar e intercambiar información.

¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato de texto utilizado para almacenar y transportar datos entre aplicaciones.

JSON utiliza principalmente pares de clave y valor.

Estructura básica

{
    "nombre": "Decide Bien",
    "tema": "Prevención",
    "activo": true
}

JavaScript vs JSON

JavaScript JSON 
const usuario = {
    nombre: "Carlos",
    edad: 16
};
 
{
    "nombre": "Carlos",
    "edad": 16
}

¿Cómo se utiliza?

Las aplicaciones web pueden utilizar JSON para enviar y recibir información desde servidores y APIs. Esto permite que diferentes sistemas puedan intercambiar datos de manera organizada.
