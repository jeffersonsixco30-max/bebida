jQuery

Una biblioteca que facilita el trabajo con JavaScript.

¿Qué es jQuery?

jQuery es una biblioteca de JavaScript creada para simplificar tareas comunes como seleccionar elementos HTML, manejar eventos y crear efectos y animaciones.

Su sintaxis utiliza principalmente el símbolo $.

Ventajas y desventajas

✅ Ventajas

  • Sintaxis sencilla.
  • Facilita las animaciones.
  • Fue muy útil para compatibilidad entre navegadores.

⚠️ Desventajas

  • JavaScript moderno puede realizar muchas tareas sin jQuery.
  • Agregar una biblioteca externa puede ser innecesario en proyectos pequeños.
